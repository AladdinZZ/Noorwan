## Pièges

- `i.decode()` d'une image différée qui n'est jamais demandée ne se résout pas : l'audit borne l'attente.
- « › » est un caractère miroir : en arabe, l'algorithme bidi le retourne déjà ; une règle RTL qui le remplace par « ‹ » le retournait deux fois.
- `'\u{2066}'` entre apostrophes n'est pas interprété par PHP : guillemets doubles obligatoires (bandeau arabe).
- Les tests prenaient le premier jeton de la page Contact, qui est maintenant celui du bandeau quand Tag Manager est réglé.
